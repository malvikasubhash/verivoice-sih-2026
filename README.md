# VeriVoice

### TRUTH IN THE VOICE

AI-powered voice cloning detection and scam-risk prototype by X-SPECT.

## Core flow

Capture → Analyze → Detect → Alert → Verify

## Features

- AI voice analysis
- Spoof probability
- Confidence score
- LOW / SUSPICIOUS / HIGH risk
- Non-speech protection
- Call Shield
- Scam reporting
- Activity history
- Learn and privacy sections

## Model

HyperMoon Wav2Vec2 deepfake audio detector.

## Important

VeriVoice provides a risk signal, not absolute proof of caller identity.
